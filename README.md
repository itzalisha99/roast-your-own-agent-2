## The line

> I gave my agent one job. It did three, documented none, and called it initiative.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`.
It checks the line first with a `validate()` gate mirroring the bounty gate:
UTF-8 text, 1–200 characters, not only whitespace, a single line.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
